# Trio Renseriet

Trio Renseriet is a Danish dry-cleaning, laundry, textile-care, and tailoring website for customers in Højbjerg and Aarhus.

The site is a Next.js App Router application exported as static files. It does not use server-side rendering, API routes, or runtime data fetching.

## Requirements

- Node.js 18 or newer
- npm
- ImageMagick only when regenerating responsive image assets

Install dependencies with:

```bash
npm ci
```

## Commands

```bash
npm run dev             # local development server
npm run lint            # ESLint
npm run build           # static export to out/
npm run verify          # lint, build, and static-export checks
npm run build:zip       # build and create out.zip for upload
npm run images:generate # regenerate 480/768/1200 WebP image variants
```

The canonical pre-PR check is `npm run verify`.

## Project shape

- `app/` contains routes, layouts, components, styles, metadata, and JSON-LD.
- `app/seo.ts` is the source of truth for site identity, local-business details, and route metadata.
- `public/priser.yaml` and `public/skraedder-priser.yaml` are build-time price sources.
- `public/` contains files copied directly into the static export. Original images are kept beside their committed responsive WebP variants.
- `out/` is generated by `next build` and must not be edited or committed.

## Static deployment

Run `npm run build` and upload the contents of `out/` to the static host. The export uses directory-style routes with trailing slashes, so the host must serve paths such as `/services/` from their generated `index.html` files and return a real 404 for unknown paths.

Read [AGENTS.md](AGENTS.md) for repository-specific operating rules and source-of-truth boundaries.
